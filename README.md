## 🚀 How to use this repository

- Browse the categories above and click on the links.  
- Use these sites to **create, customise, promote and learn** about Wapkiz and Wapaxo.  
- If any link is broken or you know a better site, please open an **Issue** or send a **Pull Request** (see below).

---

## 🤝 How to contribute

Do you want to help make this list even more complete? Follow these steps:

1. **Fork** this repository.  
2. Add the new site in the correct category (or create a new category if needed).  
3. Keep the format: `- Name – URL` (or numbered list).  
4. Submit a **Pull Request** with a short description of your suggestion.

> ✅ **Criteria for inclusion:** free sites, relevant to Wapkiz/Wapaxo site building, no malicious content.
